# Установка и обновление шаблона 1C AI DevStart для Cursor

> Это инструкция для ИИ-агента. Человеку она не нужна: порядок действий руками — в `README.md`.

Пользователь просит установить в свой проект шаблон Cursor для разработки на 1С:Предприятие
либо обновить уже установленный. Выполни шаги ниже самостоятельно. Задавай вопросы только там,
где это прямо предписано.

**ЦЕЛЬ:** файлы шаблона лежат в папке проекта, временное скачанное убрано, пользователь знает
следующий шаг.

**ГОТОВО, КОГДА:** при установке — в корне проекта есть `AGENTS.md`, `.cursor/rules/1c-rules.mdc`
и `.cursor/commands/setup-project.md`, а папки `.git` шаблона в проекте нет. При обновлении —
каталоги `.cursor/rules`, `.cursor/skills`, `.cursor/agents` и `.cursor/commands` заменены свежими,
а файлы проекта (`AGENTS.md`, `.cursor/mcp.json`, `.cursor/rules/local.mdc`, `.gitignore`)
не изменены.

## Шаг 1. Проверь, куда ставишь

Шаблон ставится в текущую рабочую папку — это будущий каталог проекта 1С.

Остановись и спроси у пользователя путь, если текущая папка — домашний каталог, `Desktop`,
`Downloads`, `Documents`, временный каталог или каталог настроек Cursor (`~/.cursor`,
`%USERPROFILE%\.cursor`). Путь не угадывай и папку проекта за пользователя не придумывай.

## Шаг 2. Определи, установка это или обновление

**Пользователь прямо попросил обновить шаблон** — работай в режиме обновления, вопросов не задавай.

Иначе смотри, что в папке. Пусто — обычная установка. Уже есть `AGENTS.md` или
`.cursor/rules/1c-rules.mdc` — шаблон, скорее всего, стоит: **остановись, покажи найденное
и спроси**, обновлять или отменить. Есть `CLAUDE.md` или каталог `.claude/` — в проекте стоит
версия шаблона для Claude Code: **остановись и спроси**, переводить ли проект на Cursor. Сам не решай.

В режиме обновления файлы проекта не трогай: `AGENTS.md`, `.cursor/mcp.json`,
`.cursor/rules/local.mdc`, `.gitignore` и прочие файлы в корне настроены под конкретный проект,
и свежий шаблон их значения не знает.

## Шаг 3. Скачай шаблон

Скачай во временный подкаталог `.devstart-tmp` внутри папки проекта — так не понадобится доступ
за её пределы. Источник — `https://github.com/sm-git-storage/1c-ai-devstart-cursor`, ветка `master`.
Хватит последнего среза, история шаблона в проекте не нужна.

Есть `git` — клонируй с глубиной 1. Нет — скачай архив
`https://github.com/sm-git-storage/1c-ai-devstart-cursor/archive/refs/heads/master.zip` под именем
`devstart.zip` и распакуй; внутри архива файлы лежат в папке `1c-ai-devstart-cursor-master`,
учитывай это в путях на шаге 4.

Команда для Windows PowerShell:

```powershell
git clone --depth 1 https://github.com/sm-git-storage/1c-ai-devstart-cursor.git .devstart-tmp
```

## Шаг 4. Разложи файлы

Перед копированием убедись, что каталог назначения существует: `Copy-Item` при отсутствующем
назначении раскладывает файлы иначе, чем ожидается, — `.cursor` теряется, а его содержимое
оказывается в корне.

**Установка.** Скопируй **содержимое** скачанного (а не саму папку) в корень проекта. Не копируй
три вещи: каталог `.git`, а также `README.md` и `install.md` — они описывают сам шаблон и в проекте
не нужны. Скрытые файлы и каталоги, начинающиеся с точки, наоборот, должны попасть в проект:
`.cursor`, `.gitignore.example`.

```powershell
Copy-Item .devstart-tmp\* . -Recurse -Exclude .git, README.md, install.md
```

**Обновление.** Замени четыре каталога шаблона целиком — `rules`, `skills`, `agents`, `commands`.
Личное правило `.cursor/rules/local.mdc` перед заменой сохрани и верни на место. Файлы-примеры
`*.example` не возвращай туда, где уже есть рабочий файл: `.cursor/mcp.json.example` — если есть
`.cursor/mcp.json`, `.cursor/rules/local.mdc.example` — если есть `.cursor/rules/local.mdc`.

## Шаг 5. Проверь результат

Убедись, что на месте `AGENTS.md`, `.cursor/rules/1c-rules.mdc`, `.cursor/commands/setup-project.md`,
а `.git`, `README.md` и `install.md` шаблона в проект не попали. В режиме обновления дополнительно
проверь, что файлы проекта остались прежними. Что-то не сошлось — скажи об этом прямо
и не рапортуй об успехе.

## Шаг 6. Убери за собой

Удали `.devstart-tmp` и, если скачивал архив, `devstart.zip`.

## Шаг 7. Передай пользователю следующий шаг

Правила, скиллы, субагенты и команды Cursor подхватывает из `.cursor/` без перезапуска, но
в уже открытом чате их может не оказаться: **начать новый чат** нужно в обоих режимах.
Не появились — `Developer: Reload Window`.

После установки добавь второе: **в новом чате выполнить `/setup-project`** — команда настроит
подключение к базе, выгрузит исходники и заполнит паспорт проекта. Сам её не вызывай: её
выполнение — отдельный разговор с пользователем.

После обновления `/setup-project` запускать не нужно: подключение и паспорт уже настроены.

Пользователь работает не на Windows — предупреди отдельно: шаблон рассчитан на Windows,
и на другой системе не заработают пакетные операции через конфигуратор (скилл `1c-batch`,
27 скриптов PowerShell) и часть `/setup-project`, которая ищет платформу в `C:\Program Files\1cv8`.
Правила, скиллы, субагенты и работа с базой через MCP от системы не зависят.

ВЫПОЛНЯЙ СЕЙЧАС: пройди шаги 1-7 и доложи результат.
